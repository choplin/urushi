# Decision Log

One row per decision made or changed, newest first. The linked document holds
the current rule and rationale; because those documents are rewritten in place,
this table is the record of when each decision was made and what it replaced.

| Date | Decision | Recorded in |
| --- | --- | --- |
| 2026-08-20 | Corrected two gaps in the TUI application value found while implementing it. `Subscription::interval` now takes the application's key alongside its period, because keying a timer by its period alone made two timers of one period one source and lost one of them silently to the latest-mapper rule; the period stays in the identity so that changing it restarts the timer. `Effect::after` and `after_latest` were added, because a one-shot delay had no expression: writing it as a future made every waiting application reach for an executor by name and read a clock the harness cannot advance, and `after_latest` composes replacement with a wait into debouncing. | [`design/tui-application.md`](design/tui-application.md) |
| 2026-08-19 | Fixed the TUI terminal layer's Rust shape: `Terminal`, `Frame`, `TerminalSession`, and `Clock` as traits Urushi owns, stated in its own vocabulary, with a Ratatui-backed implementation inside its own module rather than an adapted `ratatui::Terminal` — the terminal commits only after output succeeds and resizes only through the `Sync` barrier; the renderer an internal function serving the cursor anchor only, with foreign regions left to the caller that holds a buffer; session defaults of raw mode, alternate screen, bracketed paste, focus, and probed keyboard enhancement on and mouse off, restored on shutdown, error, panic, and partial entry; signals as declared subscriptions. | [`design/tui-terminal-ownership.md`](design/tui-terminal-ownership.md) |
| 2026-08-19 | Committed to owning the terminal layer rather than treating an adapted backend as its definition, and fixed how the gap is carried in the meantime: a design states what the terminal layer must do, the deviation is recorded at the deviating code and in the issue tracker, and no document is softened to match a backend. | [`architecture.md`](architecture.md) |
| 2026-08-19 | Added a `Grid` node that aligns column widths across rows and draws the lines between its cells, so that lining columns up no longer requires a component to decide sizes while composing — as absolute lengths, pre-wrapped text, or repeated-glyph strings written into a view before any area is known, which a layout pass cannot refuse because a text leaf's contents are opaque to it. A column carries an optional `Length` supplying its claim's kind while the cells beneath it supply the demand and the floor; `cell_padding` states one spacing a cell may replace rather than add to; each intersection's glyph is derived from the lines meeting there, after every width is decided. Rejects a component that receives `Available`, a subtree exempt from re-fitting, and corner glyphs stated per cell on `BlockStyle`. | [`design/grid.md`](design/grid.md) |
| 2026-08-19 | Stated that the clamp only caps, so an area wider than a node never widens it, a text leaf included. Replaces the reading under which a leaf given an area took that area as its width, which had made a view narrower than its area resolve to the area's width with the remainder filled. | [`design/box-sizing.md`](design/box-sizing.md) |
| 2026-08-19 | Fixed the TUI runtime's delivery and execution contract: application-defined sources as a `Stream` or a `Sender` function, asynchronous or blocking, each with an explicit `Admission` or the bounded default, always `Async` with `Delivery` internal; suppression by replacement only, with no `cancel`; `run(app)` blocking on the calling thread over a builder that supplies executor, backend, and clock, Tokio behind a runtime-owned executor boundary; a fixed startup round limit reported as an error; shutdown inside a `Sync` batch ending it at that `update`; a draw failure delivered only to a program that subscribed to terminal errors and fatal otherwise. | [`design/tui-runtime-entry.md`](design/tui-runtime-entry.md) |
| 2026-08-18 | Fixed the TUI application's Rust shape: a trait whose `Self` is the program description and whose associated `Model` the runtime owns, `update` borrowing the model mutably and returning one `Effect`; effects carrying either blocking closures or futures behind an executor boundary the runtime owns, composed by `batch` and `map`, with keyed latest-only replacement; subscriptions as declared sources — input and surface facts included — reconciled by a type-and-hash `Key` with the latest mapper winning; shutdown as `Effect::shutdown()` read from `update`'s return rather than a message. | [`design/tui-application.md`](design/tui-application.md) |
| 2026-08-19 | Made an anchor a block that carries a `Key` rather than a leaf of its own, so a region is sized by the rules every box follows and adding a key moves no geometry. A leaf would have had to answer how large it is, and the cursor and the embedded-widget uses want opposite answers. `resolve` reports each anchor's content rectangle beside the resolved rows, in tree order, unbounded by the resolved size — a region reports whether the view contains it rather than being rounded into it, so a cursor scrolled out of view is not reported as sitting on the last row — and one key to one region. | [`design/tui-view.md`](design/tui-view.md) |
| 2026-08-17 | Made the TUI runtime's `View` be `urushi::View`, withdrawing the open question that had set the type aside while it was line-oriented, so one layout model spans plain output, prompts, and full-screen applications. Adds one anchor leaf — a rectangle layout places and nothing draws — to carry the two things a grapheme rectangle cannot express, cursor placement and an embedded Ratatui widget, and has the runtime's `Renderer` consume `ResolvedView` and its placements rather than `ViewWidget`. | [`design/tui-view.md`](design/tui-view.md) |
| 2026-08-16 | Fixed display width as the sum over grapheme clusters, replacing three measures in use at once (escape-skipping, whole-string, per-grapheme sum). The sum is what a `ResolvedView` row adds up to, and wrapping and totalling must share one measure for a box to fix its width before its content is wrapped. Accepts measuring a LAM+ALEF ligature one cell wider than a terminal draws it. | [`design/rendered-output-measurement.md`](design/rendered-output-measurement.md) |
| 2026-08-16 | Split plain-text and rendered-output measurement by type: plain text is carried by the public `PrintableLines` / `PrintableText`, rendered output only by `RenderedBlock`, and ANSI-aware measurement — now resolving cursor movement to cells before measuring — is reachable only through `from_ansi`. Removed the public `visible_width` and made `wrap_text` crate-private, replacing the free `&str` width function whose ambiguous domain had let escape handling leak into the plain path. | [`design/rendered-output-measurement.md`](design/rendered-output-measurement.md) |
| 2026-08-16 | Made the underline one optional value carrying its shape and its color, removing `Modifier::UNDERLINED` and adding `hidden`, so that a single underline has one spelling and an underline color cannot exist without an underline to draw it. | [`design/underline.md`](design/underline.md) |
| 2026-08-16 | Closed the remaining canonical-form duplication by normalization rather than by type: fold an underline color equal to the foreground, once the style is final, and fold only what is inert. | [`design/style-canonical-form.md`](design/style-canonical-form.md) |
| 2026-08-16 | Chose a prompt's horizontal cursor window before Resolve, replacing the withdrawn decision to resolve a prompt unbounded in width — an unbounded axis is a measurement, so it costs every row its overflow policy. | [`design/prompt-render-plan.md`](design/prompt-render-plan.md) |
| 2026-08-16 | Stated the no-solver boundary as "a decided size is never revised, and no node is assembled twice" rather than "no node is laid out twice", so that repeating a pure measurement of a subtree — which a `Column` needs to divide its height — is inside the model. | [`design/layout-resolution.md`](design/layout-resolution.md) |
| 2026-08-16 | Made the clip marker a parameter of `Overflow::Clip` instead of a separate `Ellipsis` policy, so the glyph and its cell cost are the application's choice. | [`design/overflow.md`](design/overflow.md) |
| 2026-08-16 | Made the available area an input to layout: the `Cells`/`Fill` length vocabulary over one outer box, layout-participating min/max bounds, application-chosen overflow, and frames that always close — replacing post-hoc cropping by `max_width` and `Limits`. | [`design/box-sizing.md`](design/box-sizing.md) |
| 2026-08-15 | Defined the inline prompt rendering architecture. | [`inline-prompt-rendering.md`](inline-prompt-rendering.md) |
| 2026-08-15 | Split presentation into `TextStyle` and `BlockStyle` and adopted the four-node `View` tree resolving to one rectangle for all backends. | [`design/view-block-model.md`](design/view-block-model.md) |
| 2026-08-14 | Separated component data from component style: borrowed style plus borrowed data compose a `View`, with no output ownership. | [`design/component-data-and-style.md`](design/component-data-and-style.md) |
| 2026-08-13 | Adopted an immutable, backend-neutral style value model with a closed property vocabulary and generic `add`/`remove`; no patch or inheritance. | [`design/style-value-model.md`](design/style-value-model.md) |
