# urushi-prompt

Blocking inline terminal prompts styled with Urushi.

```toml
[dependencies]
urushi = "0.1.1"
urushi-prompt = "0.1.1"
```

Build themed `Input`, `Select`, and `Confirm` fields with synchronous validation, grouped form flow, explicit cancellation and I/O errors, and terminal cleanup. The prompt uses the same logical `Theme` as plain output and full-screen views.

The 0.1 API is in early development. See [Choose a terminal surface](https://github.com/choplin/urushi#choose-a-terminal-surface) and [docs.rs](https://docs.rs/urushi-prompt).
