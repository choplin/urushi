# urushi-derive

Derive macros used by the Urushi component model.

Most applications should depend on [`urushi`](https://crates.io/crates/urushi), which re-exports the derives intended for ordinary use. This package currently provides `#[derive(TableRow)]` for typed table rows.

The 0.1 API is in early development. See [docs.rs](https://docs.rs/urushi-derive) and the [source repository](https://github.com/choplin/urushi).
